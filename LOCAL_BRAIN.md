# Goje V8 Local Brain

V8 adds a local-first reasoning layer:
- Ollama runs locally on Windows.
- Qwen3 4B is the starter reasoning model.
- Goje.Modelfile creates `goje-brain`.
- Goje adds persistent memory and desktop tools around the model.

Run `INSTALL_LOCAL_BRAIN.bat` once. No OpenAI API key is required for local reasoning.

Ollama exposes its local API at http://127.0.0.1:11434.
